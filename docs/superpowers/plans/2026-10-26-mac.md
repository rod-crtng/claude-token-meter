# Plano — medidor no macOS (2026-10-26)

Pedido do Rod: levar o medidor pro MacBook da Sabrina. Branch `mac`, separado do
`main` (o PR da bandeja pro Angelo sai do `main` e segue pendente).

## O que impedia de rodar no Mac

1. `main._acquire_singleton` usa `ctypes.windll` (named mutex) — quebra na abertura.
2. O token: no macOS o Claude Code guarda as credenciais no **Chaveiro**
   (servico `Claude Code-credentials`), nao em `~/.claude/.credentials.json`.
3. Sem `APPDATA`, config/status caem numa pasta solta `~/claude-token-meter`.
4. Autostart cria `.lnk` na pasta Inicializar via PowerShell; `pythonw.exe` nao existe.
5. Textos e fonte de Windows ("Iniciar com o Windows", `Segoe UI`).
6. O `python3` do macOS (Xcode CLT) e 3.9; o codigo exige 3.10+.

## O que muda (Windows fica igual)

- `config.data_dir(platform)`: `APPDATA` > macOS `~/Library/Application Support` > home.
  `status.py` usa ele; `hooks.py` (standalone) duplica a regra — teste de paridade.
- Singleton POSIX: `fcntl.flock` num `instance.lock` na pasta de dados (solto quando o
  processo morre, igual ao mutex).
- `usage_client.read_token`: arquivo primeiro; no macOS, sem arquivo, le o Chaveiro com
  `security find-generic-password -s <servico> -w`. Token do Chaveiro fica em cache na
  memoria e so e relido em 401/403 (ler a cada tick poderia abrir o dialogo do Chaveiro
  a cada minuto). Continua sem renovar token: so rele o que o CLI gravou.
- `autostart`: no macOS, LaunchAgent `~/Library/LaunchAgents/com.crtng.claude-token-meter.plist`
  (`RunAtLoad`), com `sys.executable` do venv.
- Menu "Iniciar com o Mac"; fonte padrao do sistema fora do Windows.
- Icone fora do Dock (politica Accessory via objc/ctypes), desligavel em
  `mac_hide_dock` no config se atrapalhar o popup.
- `instalar_mac.sh` (uv + Python 3.12 + venv) e `iniciar.command` (duplo clique).
